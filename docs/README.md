# Demo page

`index.html` is a standalone landing page for the project: a hero, the full
screenshot gallery, features, and quick-start snippets. It has no build step
and loads no external assets.

Preview it locally with any static server, for example:

```sh
python3 -m http.server -d docs 8000   # http://localhost:8000
```

To publish it on GitHub Pages:

1. Push the repository to GitHub.
2. Open *Settings → Pages*.
3. Under *Build and deployment*, choose *Deploy from a branch*.
4. Select the `main` branch and the `/docs` folder, then save.

The screenshots in `assets/screenshots/` are real CLI output generated by
`tools/screenshots.py` (`make screenshots`).
